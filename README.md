Данный Python-скрипт содержит в себе csv-отчет. Его можно открыть, чтобы посмотреть, что произошло с каждой молекулой при конвертации. Сам Python-скрипт выдает только молекулы с проблемами (которые содержали существенные ошибки и заставляли код падать), а также создает в папке с файлами smile и sdf папки с файлами, которые содержат конвертированные файлы в pdbqt.
Для запуска скрипта необходимо:
1) Проверить, чтобы все файлы (sdf, smile и Python-скрипт) находились в одной папке.
2) Установите дистрибутив Python с conda. (У меня это Miniconda).
3) Открыть терминал на Linux/macOS; на Windows с Anaconda — открыть Anaconda Prompt
4) Ввести следующие команды по очереди, нажимая Enter после каждой:
conda create -n pdbqt python=3.11 -y
conda activate pdbqt
conda install -c conda-forge numpy scipy rdkit -y
pip install meeko gemmi
5) Для проверки установки всего нужного, введите следующую команду:
python -c "from rdkit import Chem; import meeko; print('OK')"

После запуска всех нужных команд перейдем к следующим действиям:
6) В терминале нужно активировать окружение (вставить команду):
conda activate pdbqt
7) Перейти в папку со скриптом:
cd C:\users... (после cd нужно вставить путь до папки со скриптом)
8) В самом скрипте переименовать путь (в самом конце, помечено комментариями, отдельно для sdf и smile файлов), не забыть сохранить
9) Перейти обратно в терминал и запустить конвертацию:
python convert_ligands2.py
